FEATURED PROJECT v1.00 RELEASED

PersonOS

Local-first personal learning & action system

把“我想成为什么”转化为清晰、可执行、可追踪的行动路线。系统负责组织目标、知识与进度，AI 提供建议，最终决定始终由用户确认。

  • 长期目标 → 粗粒度路线 → 阶段详情 → 最小执行单元
  • 用户用自然语言汇报，AI 生成候选更新，确认后写入进度
  • 本地知识库、学习证据、快照与复盘统一沉淀
  • SQLite 迁移、事务、审计、提醒、备份与自动化测试
